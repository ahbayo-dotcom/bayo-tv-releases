# Bayo TV — Releases

Download the latest Bayo TV from the [Releases](https://github.com/ahbayo-dotcom/bayo-tv-releases/releases/latest) page.

| Device | File |
|---|---|
| Android TV / phone (most devices, 64-bit) | `BayoTV-x.y.z-arm64.apk` |
| Older Android TV boxes (32-bit) | `BayoTV-x.y.z-armv7.apk` |
| Windows | `BayoTV-x.y.z-Setup.exe` |

`version.json` is read by the app to offer updates. This repository holds release files only — no source code.
